## What kind of evidence this is

- Every read was made with WebFetch, which returns a **model-written extraction** of a page or PDF, not the raw file. No raw HTML, PDF or download was obtained for any source, because the shell has no network access and the container browser cannot reach the sites.
- Agreement therefore shows that independent reads of the same or different publications give the same numbers as the project copy. It is **corroboration, not independent verification**, and it is not described as verification anywhere in this repo.
- Confidence: high that the project copy matches what the sources print for cells read twice or more (Federal .308 velocities and energies were read from three publications: R5, R6 and the R8 PDF); medium for cells read once; low for anything a reader could have shifted by a column (drop rows whose range captions were unclear, which were left out of R8 on purpose).
- Original PDFs: one Federal PDF was reachable (R8, a third-party-hosted copy, undated). No Hornady PDF with these tables was found. Hornady's pages are HTML only.
